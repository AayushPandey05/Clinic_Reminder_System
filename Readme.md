# Clinic Reminder System Prototype

A simple beginner-friendly prototype built to simulate an automated clinic appointment reminder workflow.

## Objective

The goal of this prototype is to reduce patient no-shows by improving appointment communication and reminder workflows.

---

## Features

- Appointment reminder workflow
- Basic patient scheduling simulation
- Automated reminder concept
- Simple and easy-to-understand implementation

---

## Workflow

Appointment Booked  
↓  
Reminder Sent  
↓  
Patient Confirmation  
↓  
Slot Management  
↓  
Appointment Tracking  

---

## Tech Stack

- JavaScript
- HTML
- CSS
- Basic Automation Logic
